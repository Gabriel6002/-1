# 采集清单：750 张精细分配（每类 2 个个体版）

物体：**mouse 鼠标 / keyboard 键盘 / cup 杯子**，每类 **2 个不同实物**
相机：**Jetson 那个 USB 摄像头拔下来插笔记本**，capture_images.py 看着预览拍
（同一相机采集+验收消除域差，且能看画面控构图）

---

## 0. 个体登记（拍之前先做，5 分钟）

给 6 个实物编号，各拍 1 张"证件照"存档，避免拍着拍着分不清谁是谁：

| 编号 | 物体 | 特征（自己填，便于区分） |
|---|---|---|
| 鼠标① | | 例：黑色有线罗技 |
| 鼠标② | | 例：白色无线 |
| 键盘① | | 例：全尺寸黑色 |
| 键盘② | | 例：87 配列 / 白色 |
| 杯子① | | **建议彩色马克杯** |
| 杯子② | | 例：白瓷 / 另一颜色 |

> ⚠️ 杯子两个里**至少一个彩色**，别两个都白/透明。
> ⚠️ 两个键盘尽量差异大（尺寸或颜色不同），否则等于只有 1 个。

## 2. 单个体 100 张模板（★核心：6 个个体各拍一遍这张表★）

> 每个个体都独立拍满 100 张，覆盖全部 6 个批次。
> 不允许"这个个体只拍某几批"，否则多样性作废。

| 批次 | 张数 | 物体状态 | 相机角度＆距离 | 光照 | 背景 |
|---|---|---|---|---|---|
| **A 俯视** | 20 | 平放，边拍边转 0/90/180/270°、挪画面位置 | 正上方 30~50cm 垂直下拍 | 正常室内灯 | 5张一换，覆盖4种背景 |
| **B 斜视45°** ★ | 27 | 平放，多种朝向 | 桌沿高度，距物体40~60cm，俯角≈45° | 正常室内灯 | 4种背景轮换 |
| **C 水平/低角** | 13 | 平放，正面＋侧面 | 镜头几乎与桌面齐平，侧前方拍 | 正常室内灯 | 2~3种背景 |
| **D 距离极端** | 15 | 平放 | 7张近特写(占画面≥1/2) ＋ 8张远景(占1/8~1/10) | 正常灯 | 混合 |
| **E 光照** | 15 | 平放，各朝向 | 俯/斜混合 | 5张台灯打亮＋5张关灯偏暗＋5张侧逆光带阴影 | 混合 |
| **F 遮挡＆出框** | 10 | 手/纸/别的物体挡住20~50%，或推到画面边缘只露一半 | 俯/斜混合 | 正常灯 | 混合 |

单个体合计：20+27+13+15+15+10 = **100** ✓
每类 2 个体 = 200，三类 = **600** ✓

**B 批（斜视45°）是验收最可能的机位，占比最高，务必拍全拍够。**

### 每类特别注意
- **mouse**：深色暗光易丢，E 批的暗光多拍两张不亏；有线鼠标线入镜没关系。
- **keyboard**：个大，A/B 批注意别拍出框（F 批才故意出框）。
- **cup**：正放/倒放/把手朝向不同都当不同状态拍；彩色那个多给几张。

## 3. 多物体同框 120 张（个体也要轮换）

一张图里每个物体各画一个框。这批直接满足验收"同时识别不少于2类"。
**每种组合内部把两个个体的搭配都拍到**，别只用固定一对。

| 组合 | 张数 | 个体搭配（每种搭配约 7~8 张） | 摆法 |
|---|---|---|---|
| mouse+cup | 30 | 鼠①+杯①/鼠①+杯②/鼠②+杯①/鼠②+杯② 各≈7 | 分开＋部分重叠都要 |
| keyboard+cup | 30 | 键①+杯①/键①+杯②/键②+杯①/键②+杯② 各≈7 | 杯子放键盘旁或压键盘一角 |
| mouse+keyboard | 30 | 鼠①+键①/鼠①+键②/鼠②+键①/鼠②+键② 各≈7 | 鼠标放键盘右侧，仿真实桌面 |
| 三类同框 | 30 | 尽量把6个个体都轮到 | 摆成真实办公桌 |

每种组合内部同样要变：俯视/斜视都拍、换背景、换光照、有远有近。

## 5. 拍摄命令

相机插笔记本后，在工程 tools 目录，按个体拍：

```bash
# 单物体：一个个体拍一批100张（--class 用类别名，个体靠你自己按顺序拍）
python tools/capture_images.py --class mouse    --limit 100   # 先拍鼠标①，拍满100停
python tools/capture_images.py --class mouse    --limit 100   # 再拍鼠标②（追加不覆盖）
python tools/capture_images.py --class keyboard --limit 100   # 键盘①
python tools/capture_images.py --class keyboard --limit 100   # 键盘②
python tools/capture_images.py --class cup      --limit 100   # 杯子①
python tools/capture_images.py --class cup      --limit 100   # 杯子②
# 多物体与负样本
python tools/capture_images.py --class mixed      --limit 120
python tools/capture_images.py --class background --limit 30
```

**按键**：空格=拍一张，a=连续采集开关，u=撤销，q=退出。
**核心动作**：拍每张时手要缓慢移动物体/相机，每张构图都不同。
连续采集时边连边动可快速铺量；原地不动连续拍摄会产生大量重复帧。
左上角看已拍张数，够一批就停换下一批。分几次拍没问题，追加不覆盖。

## 7. 关于"每类只有 2 个个体"——必读

2 个个体的多样性偏弱（尤其鼠标、键盘外观相近时）。补救和注意：

1. **靠变化补个体不足**：把角度/光照/背景/距离拉到最满。同一个鼠标在
   10 种光照 4 种背景下，比第 3 个鼠标更能提升泛化。清单里 A~F 就是干这个的。
2. **两个个体务必差异大**：两个一模一样的鼠标≈一个。挑颜色/尺寸/形状不同的。
3. **验收 20 物体测试尽量借新个体**：验收要测 20 个物体，只有 6 个个体的话，
   要用"同一物体不同摆放/光照"凑次数。**如果能临时借到额外的鼠标/键盘/杯子
   （组员的、隔壁桌的）专门用于测试、不参与训练**，测出来的 80% 更有说服力，
   也更符合"测试集独立"的规范。哪怕多借 3~4 个都好。
4. **先小批跑通再补**：可先每个个体拍 50 张（共 300）跑通训练+test20，
   看哪类弱再针对性补，别闷头拍完 750 才发现问题。

## 8. 拍完下一步

照片在 `dataset/raw/{mouse,keyboard,cup,mixed,background}/`，然后进行人工标注。

人工标注完成后，将图片和标注整理为：

```text
labeled/
├── images/
└── labels/
```

再划分数据集：

```bash
python tools/split_dataset.py --input labeled --output yolo_dataset \
    --classes mouse keyboard cup --ratio 0.7 0.2 0.1
```

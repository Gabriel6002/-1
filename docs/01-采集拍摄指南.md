# 手机拍摄采集指南

本实验的训练图片使用手机拍摄，然后传到电脑进行整理、手动标注和模型训练。

## 一、采集类别

本次实验采集 3 类桌面物体：

```text
mouse
keyboard
cup
```

每类需要覆盖不同角度、不同距离、不同光照和不同背景。

## 二、拍摄要求

拍摄时尽量保证图片多样性：

- 同一物体需要拍摄俯视、斜视、侧视等角度
- 物体可以放在画面中心、边缘或角落
- 保留近距离、中距离和远距离样本
- 更换桌面背景或周围环境
- 采集正常光照、偏暗、侧光等情况
- 可以加入适当遮挡和多物体同框图片

多物体同框图片中，需要在标注时把每个目标分别框出来。

## 三、图片整理

手机拍摄完成后，将图片传到电脑，并按类别或批次整理，例如：

```text
raw/
├── mouse/
├── keyboard/
├── cup/
├── mixed/
└── background/
```

其中 `mixed` 用来保存多物体同框图片，`background` 用来保存不含目标物体的桌面背景图片。

## 四、手动标注

图片整理完成后，使用 labelImg 或 X-AnyLabeling 进行手动标注。标注格式选择 YOLO 格式，类别顺序保持一致：

```text
0 mouse
1 keyboard
2 cup
```

标注完成后整理为：

```text
labeled/
├── images/
└── labels/
```

## 五、后续处理

标注完成后，使用数据集划分脚本：

```bash
python tools/dataset.py --input labeled --output yolo_dataset \
    --classes mouse keyboard cup --ratio 0.7 0.2 0.1
```

然后使用标注检查脚本：

```bash
python tools/labels.py --data yolo_dataset/data.yaml --show 20
```

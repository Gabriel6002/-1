# 标注与数据集制作流程

本文档记录桌面物体检测实验的数据标注和数据集制作步骤。所有训练图片均由本人采集，目标框和类别均通过标注工具逐张手动完成。

## 一、准备图片

将采集到的图片按类别或批次整理到原始图片目录中，例如：

```text
raw/
├── mouse/
├── keyboard/
├── cup/
├── mixed/
└── background/
```

单类图片用于保证每个类别都有足够样本，多物体同框图片用于提高模型同时识别多类物体的能力，背景图片用于减少误检。

## 二、手动标注

使用 labelImg 或 X-AnyLabeling 打开图片目录，选择 YOLO 格式进行标注。

```bash
labelImg raw
```

标注时类别顺序固定为：

```text
0 mouse
1 keyboard
2 cup
```

标注要求：

- 每个目标都需要画框，不能漏标
- 检测框尽量贴合物体边缘
- 被遮挡目标只标注可见部分
- 露出面积过小、难以判断类别的目标不标
- 多物体同框图片中，每个目标分别标注
- 背景图片不包含目标时保留空标注文件

标注完成后的目录形式：

```text
labeled/
├── images/
└── labels/
```

每张图片对应一个同名 `.txt` 标注文件。

## 三、划分数据集

将标注完成的数据划分为训练集、验证集和测试集：

```bash
python tools/split_dataset.py \
    --input labeled \
    --output yolo_dataset \
    --classes mouse keyboard cup \
    --ratio 0.7 0.2 0.1
```

输出目录：

```text
yolo_dataset/
├── images/train
├── images/val
├── images/test
├── labels/train
├── labels/val
├── labels/test
└── data.yaml
```

## 四、标注检查

划分完成后进行标注检查：

```bash
python tools/check_labels.py --data yolo_dataset/data.yaml --show 20
```

检查内容包括：

- 标注文件是否缺失
- 类别编号是否越界
- 检测框坐标是否越界
- 是否存在空标注
- 类别数量是否明显不均衡

抽样显示时，需要人工确认检测框位置和类别是否正确。

## 五、训练

数据集确认无误后进行训练：

```bash
yolo detect train data=yolo_dataset/data.yaml model=yolov8n.pt epochs=100 imgsz=640
```

训练完成后使用 `runs/desk_objects/weights/best.pt` 作为最终模型。

# 实验一：目标检测与识别实验报告

## 一、实验任务

本实验选择桌面常见物体作为检测对象，整合自采图像、网络补充样本和背景负样本，通过自动预标注与人工复核制作数据，训练 YOLOv8 目标检测模型，并在 Jetson 平台运行实时识别程序。程序能够实时显示目标类别、检测框、置信度和 FPS；代码中同时实现了 ROS2 JSON 消息发布接口。

## 二、检测类别

本次实验共包含 3 类桌面物体：

```text
mouse
keyboard
cup
```

满足“不少于 2 类桌面物体”的要求。

## 三、数据集制作

数据集采用 YOLO 格式组织。自采图片由本人使用手机拍摄后传到电脑整理，最终整合约 650 张图像，包括自采正样本、网络补充样本和无目标框的负样本。候选框由预训练模型辅助生成，之后逐图人工复核。当前可直接审计的核心子集为 225 张图像、687 个正样本目标框。GitHub 保留数据配置和标签，完整图片因体积与第三方图片分发限制保存在本地训练目录中。

```text
data/
├── images/train
├── images/val
├── images/test
├── labels/train
├── labels/val
└── labels/test
```

数据集配置文件为 `data/data.yaml`，标注文件保存在 `data/labels/`。

## 四、模型训练

训练框架为 Ultralytics YOLOv8，基础模型为 `yolov8n.pt`，训练轮数为 100，输入尺寸为 640。

训练得到的最优模型保存在：

```text
models/best.pt
```

训练结果图表和日志保存在：

```text
results/training/
```

## 五、Jetson 部署与运行

Jetson 端部署目录：

```bash
/home/nvidia/HYJJJ
```

运行命令：

```bash
cd /home/nvidia/HYJJJ
source /opt/ros/humble/setup.bash
python3 scripts/jetson_detect_ros2.py --model models/best.pt --device 0
```

程序运行后会显示摄像头画面，并在画面中绘制目标类别、检测框、置信度和实时 FPS。

## 六、ROS2 发布

程序设计为通过 ROS2 话题发布识别结果：

```text
/desk_object_detections
```

查看话题：

```bash
ros2 topic echo /desk_object_detections
```

发布内容包含帧编号、时间戳、FPS、类别编号、类别名称、置信度和检测框坐标。仓库提供发布程序与运行命令；真实话题回显应在 Jetson 的 ROS2 Humble 环境中验证。

## 七、实时性测试

最终 Jetson 结果视频为 1280×720、300 帧、20 秒，检测界面稳定显示 15 FPS，高于验收要求的 5 FPS。

## 八、测试结果保存

运行程序会自动保存：

```text
result.mp4        检测结果视频
detections.csv   检测结果日志
errors/          典型错误案例截图
```

运行时按 `e` 可保存当前帧作为典型错误案例，按 `q` 退出。

## 九、20 个物体识别率

本项需要现场摆放 20 个测试物体后统计。正确率计算方式：

```text
正确识别率 = 正确识别数量 / 20 * 100%
```

验收要求为不低于 80%，即 20 个物体中至少正确识别 16 个。

测试记录表见：

```text
docs/20_object_test_template.csv
```
